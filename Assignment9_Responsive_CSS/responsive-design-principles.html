Core Principles of Responsive Design

Fluid Layouts

Layouts built with relative units so content resizes smoothly with the viewport.

width: 100%;

Flexible Media

Images and media scale within their containers instead of overflowing the page.

max-width: 100%;

Breakpoints

Specific viewport widths where the layout changes to better fit the screen.

@media (max-width: 600px) { }
