Responsive CSS Cheat Sheet

Filters

filter: blur(), grayscale(), sepia(), and more are used to apply visual effects to images and elements.

Media Queries

@media (max-width: 700px) { ... } applies styles only when the condition, such as a screen width, is met.

Responsive Design

An approach where layouts adapt fluidly to different screen sizes using flexible units, Flexbox, and Grid.

Typography

clamp(1rem, 2vw, 1.5rem) allows font sizes to scale smoothly between a minimum and maximum value.
