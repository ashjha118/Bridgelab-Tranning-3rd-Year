Box-Sizing Comparison

Both boxes have width: 300px and padding: 30px — see the difference.

content-box Default

Rendered width: 360px

  • Set width: 300px
  • Padding: 30px each side
  • Total = 300 + 30 + 30 = 360px
  • Padding is added outside the width
box-sizing: content-box;

border-box Recommended

Rendered width: 300px

  • Set width: 300px
  • Padding: 30px each side
  • Total = still 300px
  • Padding is included inside the width
box-sizing: border-box;

Why does this matter?

With content-box, adding padding increases the total size of the element, which can break layouts unexpectedly. With border-box, the width stays exactly as declared — padding is absorbed inside — making layouts far more predictable. That's why most CSS resets use * { box-sizing: border-box; }.
