# Assignment 4 – JavaScript Solutions

This folder contains a separate JavaScript solution for each of the 9 questions.

## Files
- `q1_product_manager.js` – Product class, discount, array filter.
- `q2_student_form_validator.js` + `q2_student_form.html` – Student form and RegExp validation.
- `q3_library_management.js` – Book class, issue/return and ISBN search.
- `q4_custom_form_builder.js` + `q4_custom_form_builder.html` – Dynamic form generated by a class.
- `q5_movie_ticket_booking.js` + `q5_movie_ticket_booking.html` – Movie booking validation and booking object.
- `q6_employee_management.js` – Employee class, annual salary, bonus and reduce().
- `q7_login_form_validation.js` + `q7_login_form.html` – Login validation using RegExp.
- `q8_dynamic_object_updater.js` + `q8_dynamic_object_updater.html` – Edit and display the user object.
- `q9_shopping_cart.js` – Cart class, total and coupon validation.

## How to run

### Node.js questions
Open Terminal in this folder and run:
```bash
node q1_product_manager.js
node q3_library_management.js
node q6_employee_management.js
node q9_shopping_cart.js
```

### Browser form questions
Open the matching HTML file in a browser. Each HTML file already loads its matching JavaScript file:
- `q2_student_form.html`
- `q4_custom_form_builder.html`
- `q5_movie_ticket_booking.html`
- `q7_login_form.html`
- `q8_dynamic_object_updater.html`

The assignment asks for separate `.js` files, so each question has its own JavaScript file. HTML files are included only where a browser form/DOM is required.
